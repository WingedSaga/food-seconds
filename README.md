# Еда секунды

Внутренний сервис заказов для небольшой компании. Использует **те же** таблицы `users` и JWT, что и «Новости секунды».

## Запуск

1. Выполните `server/db/migrations/001_food_seconds.sql` в SQL Editor того же Supabase-проекта, где живёт News Seconds.
2. Скопируйте `server/.env.example` в `server/.env` и задайте те же `SUPABASE_URL`, `SUPABASE_SERVICE_ROLE_KEY` и `JWT_SECRET`, что у News Seconds.
3. `cd server && npm install && npm start`
4. `cd client && npm install && npm run dev`

В `client/.env` укажите URL API, например `VITE_API_URL=https://food-seconds-api.example.com/api`.

Для production-сборки выполните `npm run build` в `client`, а каталог `client/dist` разместите на статическом хостинге. Сервер должен быть доступен по HTTPS и иметь `CLIENT_URL` со значением адреса фронтенда.

## Возможности

- динамические категории и блюда, которые создаются только через админ-панель;
- корзина, комментарий, наличные/перевод, QR-код с номером и полной суммой;
- настраиваемые фиксированные или процентные чаевые;
- экран очереди `/manager` с автоматическим обновлением каждые 3 секунды;
- админ-панель `/admin` для меню, доступа участников, оплаты и чаевых;
- личная история заказов `/orders`.

Администраторы News Seconds автоматически считаются администраторами Еды секунды. Доступ участников и менеджеров выдаёт только администратор в разделе «Менеджеры».
